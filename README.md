# Zipstore handoff

Reference material for developers. Nothing here is a product spec by itself: the specs are the pages and the Figma file linked from the task.

- `flying-animations/` : the flying animations. `flying-animations.reference.js` and `.css` are the prototype code (not a drop-in module, the header lists what it needs from the page). `index.html` is the spec page, the `.jpg` files are stills.
- `reveal-store/` : the Reveal screen (store window and phone with a scrolling page). `index.html` is the spec page, `reveal-store.mp4` is the animation, `mobile-page.jpg` is the mobile page from Figma.

All numbers (counts, speeds, timings) are prototype values and can be tuned.
